Grammar Focus
Rule 1 — This / That (singular)
Use THIS for things near you. Use THAT for things far from you.
This is a book. (near) · That is a car. (far)
Usa THIS para lo que está cerca, THAT para lo que está lejos.
Rule 2 — These / Those (plural)
Use THESE for plural things near you. Use THOSE for plural things far.
These are books. (near) · Those are cars. (far)
Usa THESE para lo cercano en plural, THOSE para lo lejano en plural.
Rule 3 — Questions
Use What is this / that? to ask about things.
What is this? — It is a pen. · What are those? — Those are apples.
Usa "What is this/that?" para preguntar sobre objetos.
